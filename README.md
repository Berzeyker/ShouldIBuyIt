# 🛒 Should I Buy It?

> An intelligent shopping assistant designed to help users make conscious financial decisions, evaluate real needs, and prevent impulse buying.

---

## ✨ Key Features

* **Decision Matrix:** An interactive questionnaire evaluating psychological and economic factors before confirming a purchase.
* **Wishlist Management:** Track pending items with built-in "cooling-off" period reminders.
* **Budget Impact Analysis:** Real-time visualization of how a potential purchase affects your monthly balance.
* **Cross-Platform Experience:** Built for seamless usage across mobile devices (iOS/Android) and web.
* **Conscious History:** Log past decisions and monitor the total savings generated by avoiding unnecessary purchases.

## 🛠️ Tech Stack

| Layer | Technologies |
| :--- | :--- |
| **Frontend** | Ionic Framework, Angular |
| **Styling** | Tailwind CSS / SCSS (Glassmorphism UI) |
| **Mobile Bridge** | Capacitor (Native iOS & Android compilation) |
| **Backend** | Node.js (Express) / FastAPI |
| **Database** | PostgreSQL |
| **Containerization** | Docker |

---

## 📋 System Requirements

Make sure you have the following installed in your local development environment:
* **Node.js:** v18.x or higher
* **npm:** v9.x or higher
* **Ionic CLI:** Installed globally (`npm install -g @ionic/cli`)
* **Xcode:** (macOS only) Required for building and testing the iOS version
